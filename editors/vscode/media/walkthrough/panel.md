## Ask it something

The panel is in the activity bar. Open it and type — no configuration, no
project setup.

Two things worth knowing on the first run:

- **The file you have open is named, not sent.** Arcturn tells the model which
  file you are looking at and what you have selected; the contents travel only
  when you `@`-mention a file or ask for something that needs to read it. The
  chip above the composer says exactly what is going along.
- **Nothing is written without you.** Edits arrive as a permission prompt inside
  the panel. `Review Pending Changes` opens them as a real diff before anything
  touches disk.

`Ctrl+Alt+A` opens Arcturn in a terminal instead, running the same engine.
