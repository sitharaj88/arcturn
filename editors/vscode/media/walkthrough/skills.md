## Teach it your work

A bare agent knows how to code. It does not know how *your* team reviews, ships,
or argues about architecture — so Arcturn keeps that in files you can read,
version, and disagree with.

```bash
arcturn add sitharaj88/arcturn/kits/project-setup
```

That installs a **kit**: a set of roles, each with its own tool lane, and
workflows that sequence them. `/workflow app-setup` chooses a stack with its
costs named, scaffolds with the ecosystem's own generator, and proves the
boundary check fails when a rule is broken.

Thirteen kits are on [arcturn.dev/hub](https://arcturn.dev/hub) — code review,
test integrity, failure design, mobile foundations, system design. Each page
shows the actual prompt, so you can read what a role does before you install it.

Type `/` in the panel to see what this workspace already has.
