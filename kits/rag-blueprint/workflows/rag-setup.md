Run it as `/workflow rag-setup <what the system must answer, for whom, over which data>`.

The pipeline that turns "we want RAG" into a reviewed, tested, costed system in
your own repository, in your own languages, on the infrastructure you already
run. Nothing here makes Arcturn a dependency of the system it builds: the code
and the eval suite land in your tree, and these workflows stay behind as the
thing that keeps them honest.

**Writes are single-threaded.** Stage 3 writes one file (the ADR) and stages 4
through 10 write code one slice at a time. Every write-lane step's diff is
replayed into your checkout with `git apply` — never a three-way merge — so two
steps that touched one file would fail at apply time. Serializing the build
also fixes its real dependency order: retrieval must match the index schema
ingestion created, and observability instruments both. Each build slice is cut
into two or three small steps so that no single step is scoped as an entire
subsystem — a step that needs most of its turn ceiling to finish is a step that
retries, and a step that retries annoys everyone who runs the pipeline.

**The ADR is carried by a file, not by the prompt.** `{{prev}}` holds only the
immediately previous stage, so stage 3 writes `docs/adr/rag-architecture.md`
and every later stage reads it. A build step reads its contract from that file
and treats `{{prev}}` as the running report of what the prior step landed. A
stage that cannot read its thresholds invents them and reports PASS against its
own invention.

**Under plan mode this run stops at stage 3**, the first write-lane step, after
paying for the survey and the threat model. Run it outside plan mode.

**Stage 12 needs a scratch target.** The red-team drills write documents into a
corpus; the role refuses and reports `NO-ORACLE: no scratch target` unless it
can confirm a disposable index and a non-production credential from a config
file. Nothing in this kit can tell a scratch index from a live one — see the
README's SCRATCH-CORPUS-ONLY section before you run it.
