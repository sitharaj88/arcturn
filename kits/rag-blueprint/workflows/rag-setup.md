Run it as `/workflow rag-setup <what the system must answer, for whom, over which data>`.

The pipeline that turns "we want RAG" into a reviewed, tested, costed system in
your own repository, in your own languages, on the infrastructure you already
run. Nothing here makes Arcturn a dependency of the system it builds: the code
and the eval suite land in your tree, and these workflows stay behind as the
thing that keeps them honest.

**Writes are single-threaded.** Stage 3 writes one file (the ADR) and stages 4,
5 and 6 write code one slice at a time. Every write-lane step's diff is replayed
into your checkout with `git apply` — never a three-way merge — so two steps
that touched one file would fail at apply time. Serializing the build slices
also fixes their real dependency order: retrieval must match the index schema
ingestion created, and observability instruments both.

**The ADR is carried by a file, not by the prompt.** `{{prev}}` holds only the
immediately previous stage, so stage 3 writes `docs/adr/rag-architecture.md`
and later stages read it. A stage that cannot read its thresholds invents them
and reports PASS against its own invention.

**Under plan mode this run stops at stage 3**, the first write-lane step, after
paying for the survey and the threat model. Run it outside plan mode.

**Stage 8 needs a scratch target.** The red-team drills write documents into a
corpus; the role refuses and reports `NO-ORACLE: no scratch target` unless it
can confirm a disposable index and a non-production credential from a config
file. Nothing in this kit can tell a scratch index from a live one — see the
README's SCRATCH-CORPUS-ONLY section before you run it.

2. @rag-threat-modeler Threat-model the pipeline implied by the survey below, before it exists. Per threat give vector, blast radius, the mitigation you demand and the drill that would prove it bites. Cover indirect prompt injection through retrieved content; corpus poisoning by both mechanisms; entitlement leaks in all three places — ingestion-only filtering, a filter that degrades recall until the system falls back, and a cache keyed without the caller's entitlement; cross-tenant retrieval and who may write the tenant label; exfiltration channels; denial of wallet through the expensive path; secrets reaching the index; and the evaluation set as an attack surface. Rank by blast radius, mark any threat resting on an UNKNOWN as UNKNOWN-BLAST with its question, and cite no identifier you did not read this session. Survey: {{prev}}

Every demanded mitigation appears or is declined with its reason. Label every number a prediction. Inputs: {{prev}}
